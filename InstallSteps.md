Via [NOMM](https://github.com/Combat787/NOMM) one-click download (recommended):
- Install Blueprinter from NOMM if you do not have it already
- On the Discover tab, search for 'MultiMissile'
- Click the download button
- Done

Manually:
- Ensure you have BepInEx and the [latest Blueprinter version](https://github.com/nikkorap/NOBlueprinter-Releases/releases/latest)
- Download Multi-Missile.dll
- Drop Multi-Missile.dll in ./BepInEx/Plugins
- Done
